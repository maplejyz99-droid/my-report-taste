# My Report Taste v0.1.0

首个公开发行版，将个人汇报偏好库拆分为中性的内容工作流和明确选择才启用的作者预设。

## 本版内容

- 学术 Oral、研究进展、PPT/PDF/Markdown 的内容与验收流程。
- 35 张文字模式卡、11 条路由、31 个检查标记。
- 逐页计划、版本比对、双语讲稿与真实短版的检查工具。
- 保留官方模板、清晰原图表与当前用户意图的优先级。
- 不覆盖既有安装的安装脚本，以及脱敏检查和可重复 ZIP 打包。
- 原创 5 页合成示例，包含输入、计划、可编辑 PPTX、构建源代码和双语讲稿。

## 使用前需知

本项目不自带通用幻灯片渲染器。部分工具需要 Pillow、LibreOffice 或 Poppler；示例重新生成需要宿主已有 Artifact Tool。检查通过不等于科学内容已由领域作者确认，也不等于所有投影和 Office 环境都已测试。

本项目自己的代码、说明和合成示例采用 MIT；原始参考素材和字体未随发行版分发。
