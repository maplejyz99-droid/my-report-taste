# 示例核验记录

日期：2026-10-07。版本：synthetic-study v1。

## 依据与范围

事实源是 [source.json](source.json)，所有数字由作者编写用于教学。立场为 factual，不提供部署建议；不需要把这个示例的蓝色写入使用者偏好。没有前一版成品，版本差分不适用。

[页面计划](slide-plan.md) 的标题链是：比较问题 → 筛选流程 → 全部设置的结果 → 尚未测量的边界 → 备份计算。S01–S04 为 main，S05 为 backup。每页在备注中保留稳定 ID 和角色。

## 已执行的核验

- PPTX 文件结构、5 页数量、16:9 画布、标题几何和 Arial 字体声明检查通过。
- 第 3 页包含原生表格，3 个设置全部保留；表格没有合计行，因此工具的“合计运算检查”不适用，不能据此声称差值已自动验证。
- 对照 JSON 核算：紧凑设置准确率提高 2.0 个百分点，耗时减少 35 毫秒；相对耗时减少约 29.2%。大筛选准确率 86.5%，延迟 160 毫秒，均完整保留。
- 5 页均已在 Artifact Tool 以 1280 × 720 渲染并逐页查看。未观察到文字遮挡、出界或表格裁切；流程箭头指向后继阶段，合成标记与页码每页可见。
- 查看整套页面：问题页、线性流程页、结果表页、边界页、备份计算页承担不同职责；没有反复堆叠三张卡片。
- 中英文正文逐页核对同一数字、单位和结论强度。两种语言都明确合成数据身份，备份页不计入主讲预算。
- 讲稿检查无结构错误。S03/S05 的跨语言数值提示来自英文 `percent` 与中文 `%` 的书写差异；已人工核对数值一致，保留自然表达，不伪造全绿结果。
- 按默认语速并加入每页 5 秒停顿，英文完整稿估时约 2.45–2.78 分钟，中文约 2.38–2.98 分钟。主讲预算为 3 分钟。

页面计划与最终 PPTX 比对、原生表格 JSON 一致性和短稿检查由仓库命令及单元测试复核，完整发行检查结果见 [发布验证](../../docs/release-verification.md)。
