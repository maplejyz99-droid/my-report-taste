# 示例任务简报

这是作者编写的教学夹具，不是真实论文。事实源是 [source.json](source.json)；数字仅用于演示比较口径、内容组织和验证。

- 用途：英文现场研究汇报示例，约 3 分钟；4 张主讲页、1 张备份页。
- 读者：理解准确率与延迟，但不熟悉候选筛选的同事。
- 交付：逐页计划、可编辑 PPTX、中文和英文逐页讲稿。
- 本示例明确选择蓝色 `author-light`，仅代表这一示例；不建立安装者的长期偏好。
- 不使用外部品牌、论文截图、下载字体、动画、视频或生成式图片。
- 合成标签必须出现在每页和两份讲稿里；不补造数据集、显著性、重复实验或硬件。
- 立场：事实比较，不提出部署建议，不将流程图当作实验结果。
- 结构：比较问题 → 筛选流程 → 完整三行结果 → 尚未测量的边界；备份页只留指标定义与差值计算。

演示包展示一种合格的证据组织方式，不用于证明 skill 在任意论文上都能产出同等结果。
