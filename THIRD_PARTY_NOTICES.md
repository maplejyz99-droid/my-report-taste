# Attribution and distribution boundaries

The repository LICENSE covers this project's own scripts, documentation, derived design analysis, and original synthetic examples. It does not grant rights to external source documents, names, trademarks, brands, figures, photographs, fonts, or linked websites.

The reference catalog preserves public source links where available. Text cards describe abstract layout/narrative principles; source slides, reports, screenshots, videos, logos and font binaries are not distributed. A card's source-license field describes the external source, not a replacement license for it. Unknown source permission remains unknown.

Some references originated in a private collection. Private feedback, local source filenames, source files and quantitative inspection logs were excluded. A design card is not evidence that its source was independently revalidated for this release, nor that the source author endorses this project.

Optional fonts mentioned in the documentation include Adobe Source Han Sans, Source Han Serif, and Source Sans 3. Obtain them directly from their official repositories and preserve their SIL Open Font License notices if redistributing them:

- https://github.com/adobe-fonts/source-han-sans
- https://github.com/adobe-fonts/source-han-serif
- https://github.com/adobe-fonts/source-sans

No font download occurs during installation. No Microsoft font is bundled.

The synthetic demonstration is original fixture data and presentation material created for this repository. It contains no measurements from a real research project. Core Python helpers use the Python standard library; Pillow and external rendering tools are optional dependencies under their own licenses and are not vendored here.

The style gallery contains original editable pages and their rendered PNG previews using that same synthetic fixture. It includes no screenshots from the external reference decks. The gallery's Arial and Courier New font names are layout choices, not redistributed font binaries. Its optional builder requires a host-provided `@oai/artifact-tool`; neither that package nor its license is supplied by this repository.

If you add an asset, document its exact source, license and allowed redistribution before including it. An asset being publicly viewable or supplied in a chat does not itself establish redistribution rights.
