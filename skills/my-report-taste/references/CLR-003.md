## 设计推断

- 暖色的价值来自稀缺性；频繁使用会立刻破坏该模式。
- 深色页面的可读性依赖足够的明度阶梯、较粗文字和更宽松的行距。
- 该体系适合短篇、投影和品牌叙事，不适合长时间连续查阅的高密表格。
- 颜色 token 只是光场的锚点，不能把 `canvas` token 直接铺满全页；高级感来自近黑、局部照明、表面层和暗角之间的连续过渡。
- 比较页最稳妥的差异编码顺序是：位置 / 排序 → 字重 / 明度 → 直接标签 → 局部短导轨 → 独立卡片的低对比描边；整块换底色与连续表格的整行闭合框都不作为默认手段。

## 内容与叙事规则

- 先用尺度、位置、明度和字重建立主次，只有页面唯一机制、风险或决策点才使用暖色。
- 同一章节保持石油蓝与蓝灰角色稳定，不为普通类别随机增加色相。
- 高密深色页前后安排幕封、低密列表或近黑留白页，控制连续阅读负荷。
- 图表的当前 / 主要系列优先用白色或更亮蓝灰；暖色不是默认“当前值”颜色。
- 暗部中的辅助信息必须仍可读，不能把必要限定条件隐藏为低对比灰字。
- 同级卡片、表格行与方法项共享统一蓝灰表面。独立卡片可用低对比细描边；连续表格的主选项只提高关键文字明度 / 字重并使用直接状态标签，必要时加短边导轨，不增加整行闭合框。风险项用低面积陶土色文字 / 窄边标记，不改变整行底色。

## 视觉与版式配方

- 近似重建 token：
  - `cover-black`: `#010101`
  - `section-bg`: `#03090D`
  - `light-field-edge`: `#01080C`
  - `light-field-base`: `#071F29`
  - `light-field-glow`: `#10323E`–`#173F4B`
  - `surface`: `#1B313A`
  - `surface-strong`: `#243B45`
  - `grid-cover-only`: `#102229`
  - `text-strong` / `white`: `#E7E9EA`
  - `text-body`: `#E7E9EA`
  - `muted` / `text-muted`: `#A5AFB2`
  - `line`: `#536168`
  - `source-focus-candidate`: `#C9A84A`
  - `generated-focus-default`: `#C5CBC9`
- 这些是栅格近似值，不宣称为 LENZ 官方主题色。
- 背景配方不是渐变条：以近黑外缘为底，叠加 1–2 个宽而软的石油蓝 / 青蓝照明区，再加接近不可见的细颗粒与暗角；禁止清晰光束、炫光、强云纹或可识别背景图案。
- 内容页默认不显示明显全页网格；封面 / 幕封可使用低对比局部网格与圆环，但二者都不能抢过主标题。
- 比较表默认所有行共同组成一块 `surface`，行间只使用内缩 1 px 低对比分隔线。主选项使用 `white` 关键文字、较高字重与直接状态标签；风险行只增加 4–6 px 陶土色局部左标记与状态文字。整表的“围合预算”最多一层，不叠加逐行边框或选中行闭合框。
- 约 85%–95% 的视觉面积由近黑、石油蓝和蓝灰承担；来源暖色通常低于 1%。经过生成反馈，普通复用默认用低饱和暖灰白建立焦点，不主动引入黄 / 金。
- 主结论可用白字、尺寸和位置突出；不默认使用暖色。
- 若确有来源级唯一机制焦点，暖色只留给该单点；普通当前值、标题、卡片和图表系列仍使用白或蓝灰。

## 媒介适配

- PPT：适合封面、章节幕封、战略图和组织文化页；投影前检查暗部层级是否丢失。
- PDF：短篇可全文使用；长篇建议与浅底正文分段，避免连续阅读疲劳。
- 图表：历史、次要和结构使用灰 / 蓝灰；当前或主系列优先用白或更亮蓝灰，只有唯一焦点才用琥珀。
- 中英文：文字角色不随语言改变；小号灰字必须满足普通屏幕可读性。

## 反模式与边界

- 不把该体系称为“黑金”并增加金色边框、渐变、光效或阴影。
- 不将 `focus` 分配给多个类别、多个方法或每页标题。
- 不把一次来源暖色扩展成大面积芥末黄卡片、整条金色曲线、多枚流程节点或每页决策标签。
- 不在深色底上使用低对比细灰正文。
- 不复制来源背景纹理、品牌圆环和专有色值资产。
- 不把 `light-field-base` 或旧 `canvas-alt` 作为整页唯一平涂色；也不以明显方格网掩盖背景缺少空间层次。
- 不使用黑 / 蓝灰 / 红褐交替行，或按 FSDP2、PP4、TP4 等方法绑定整块底色；方法不是颜色语义。
- 本预设不在连续表格的一行四周增加亮色闭合边框，以免与整表表面和行分隔线竞争；彼此独立的卡片可按需使用细边。
- 不使用强云纹、颗粒墙纸、霓虹光束或“科技蓝渐变”替代安静的非均匀光场。
- 不用本条目替代研究进展与工程类例行汇报已确认的明亮蓝色默认。

## 验收标准

- `gate:clr-003.scarce-warm-focus` 去掉暖色后，页面仍有完整层级；暖色只负责最后一级聚焦。
- 灰度模式下仍能识别标题、表面、边界、正文和辅助信息。
- 连续浏览时存在深浅与密度呼吸，不是十几页同样沉重的深色卡片。
- 每个暖色对象都能回答“为什么它是全页唯一焦点”。
- 若页面没有唯一机制焦点，应当完全不使用饱和暖色；去掉黄 / 金后仍应保留 LENZ 气质。
- `gate:clr-003.nonuniform-dark-field` 背景九宫格取样应呈现多个近黑 / 石油蓝明度，而不是九格近似同一色；同时最亮背景区仍必须明显暗于正文和数据表面。
- 比较页的同级行移除文字后应看起来属于同一组件系统；区分状态所用的彩色填充面积应接近零。
- 连续表格缩略图中应先被识别为“一张表”，而不是五张叠放卡片；去掉文字后仍只有一层主要围合，发丝线不会被读成卡片边框。
