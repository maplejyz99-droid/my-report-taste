# 汇报参考素材接收指南

## 最小信息包

任何格式都尽量同时提供：

1. 素材本身或稳定 URL。
2. 精确位置：页码、幻灯片号、截图区域、网页区块或视频时段。
3. 用户原话：具体喜欢或不喜欢什么。
4. 未来用途：组会、项目汇报、论文答辩、会后 PDF、客户提案等。
5. 复用边界：只学结构、只学配色、允许使用模板，或不要照搬哪些元素。

只收到素材而没有解释时，可以分析并创建 `candidate/hypothesis`；不得声称已经知道用户喜欢其中全部设计。

## 各格式的价值

### PPT、PPTX 或 Keynote

最适合研究幻灯片顺序、母版、网格、对象层级、字体和可编辑结构。优先接收原文件，并让用户指出幻灯片号。若只喜欢局部，不要把整套模板视为全局偏好。

### PDF

最适合研究完整分页、印刷版面、长报告节奏和最终视觉。要求页码与关注点。PDF 通常不能可靠暴露原始母版、动画或字体许可，因此这些信息未知时不要推断。

### 网页 URL

最适合研究公开案例、模板库和交互演示。要求具体页面或区块，而不是只给网站首页。对登录后页面、会变化的页面或动效，补充截图或短录屏。只提炼公开可见原则，不复制未知许可的源码与品牌资产。

### 截图或图片

最适合快速收藏单页、局部版式、图表、色彩和字体层级。优先同时提供一张包含上下文的整页图和一张局部高清图。截图无法证明跨页节奏、真实字号、母版与动画。

### 视频、GIF 或录屏

最适合研究章节转场、逐步揭示、缩放和演示操作。提供起止时间与喜欢的动作。短录屏优于长视频；静态关键帧可作为补充，但不能代替时序证据。

### Markdown 或纯文本

最适合研究标题层级、论证顺序、重点标记和从内容源到页面地图的转换。指出哪些段落必须保留、哪些可进入附录、哪些是核心结论。

## 推荐提交模板

```text
收藏：<文件、附件或 URL>
位置：<第 X 页 / 幻灯片 X–Y / 网页区块 / 00:12–00:18>
喜欢：<具体元素与原因>
不喜欢或不要照搬：<边界>
以后用于：<汇报场景>
优先级：<核心偏好 / 普通参考 / 先作为候选>
```

一次可以提交一个完整文件，也可以批量提交三到五个明确参考。大量没有定位和评价的链接只适合先建立候选，不适合直接更新长期品味。

## 分析顺序

1. 先看完整素材的结构、顺序和重复规则。
2. 再看用户指定页面的内容职责、视觉层级、网格、色彩、字体与证据表达。
3. 对动态素材补充初始态、中间态、结束态和触发条件。
4. 对可编辑文件区分真实母版/样式与手工摆放。
5. 输出“已验证事实、设计推断、未知信息”三类结论。
