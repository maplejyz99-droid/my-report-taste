## 设计推断

- “高级感”主要来自约束一致，而不是装饰数量：单主色、稳定网格、精确边距、微型 chrome、少量异形卡片和清楚的事实状态。
- 这套页面不是岛村 `GRD-004` 那种会后独立阅读型高密度；它属于“投影型中高证据密度”：
  - 宏观层面仍保留大标题、大数字和大图表；
  - 微观层面同时提供口径、预测状态、阈值、风险、来源和下一步；
  - 信息层数较多，但主要对象数量受控。
- 高级感还来自“形状角色稳定”：切角只用于重点数据或中心对象，普通说明卡保持安静；如果所有卡片都异形，效果会迅速模板化。
- 图表布局成功的关键是“结论—证据—边界”同页：标题给判断，曲线给证据，预算线与 OOM 点给工程边界。

## 内容与叙事规则

- 每页标题先表达可验证结论，不使用“参数量”“结果分析”“方案对比”等空标题。
- 页面必须区分精确值、预测值、预算线、物理线和未实测状态；高级感不能建立在弱化不确定性之上。
- KPI 页只保留三个最重要指标；更多参数进入页脚、注释或附录。
- 图表页同时给出结论、口径、单位、阈值和例外点，但不再叠加第二张竞争图表。
- 系统 / 方案页保留一个中心对象和最多四至六个外围模块；成熟度、风险或优先级通过边框、位置和低频例外色表达。

## 视觉与版式配方

- 画布：`16:9`，外边距约页面宽度的 `4%–5%`，固定三段页眉与双段页脚。
- 背景：内容页使用近白底 + 极浅测量网格；封面使用单一高饱和蓝场。
- 色彩比例：中性与近白约 `75%–85%`，蓝色层级约 `15%–25%`，珊瑚例外色低于 `3%`。
- 标题区：左侧结论标题占主轴，右侧只放两至三行口径或决策解释，不能形成第二标题。
- KPI 卡：三列不等权或等宽排列；标签小、数字大、解释短；只允许一张高饱和主卡。
- 图表页：标题 / 短注约占上方 `18%–24%`，图表画布约占 `60%–70%`，页脚保留口径与状态。
- 曲线图：轴与网格弱化，主线保持单色；阈值线使用虚线和直接标签；关键点使用空心或实心圆，风险点才使用例外色。
- 系统图：中心块面积约为普通外围卡的 `1.4–2` 倍；关系线用主色浅阶，避免粗箭头和阴影。
- 形状：异形切角只分配给封面状态、重点 KPI 或中心模型，普通卡片保持圆角矩形或无明显造型。

## 媒介适配

- HTML deck：保留 `PAG-001` 的镜头缩放、数字递增、路径绘制与中心展开。
- PPTX：静态终态可直接复用；对象动效可用 Morph、Zoom 和简单进入近似，优先保证可编辑与现场稳定。
- PDF：使用四页静态终态；适当补充来源和口径，但不得通过缩小字号把它改造成 `GRD-004` 式阅读报告。
- Markdown：保留完整参数、假设和推导；导出时抽取结论、关键数字、阈值和风险，不按原始段落机械切页。

## 反模式与边界

- 不把“信息密集”理解为减小字号、压缩行距或把完整 Markdown 塞进一页。
- 不让每张卡片都使用切角、渐变或发光；异形必须对应重点角色。
- 不为每个方法分配一个高饱和颜色；继续使用单主色 + 一个低频风险色。
- 不把预测值排得像实测值；状态标签、脚注和风险提示必须保留。
- 不在图表画布上同时堆放长图例、大段说明、第二坐标轴和多个浮动注释框。
- 不把这套投影型密度直接用于年度报告或长篇独立阅读 PDF；后者仍按 `GRD-001` 或 `GRD-004` 处理。
- 不把当前四页的内容结构固化为万能模板；保留设计语法，页面职责仍按材料重新选择。

## 验收标准

- 缩略图总览能看到稳定的蓝白节奏、固定 chrome 和清楚的页面职责变化。
- `gate:grd-005.three-second-evidence` 每页在三秒内能定位主结论、核心证据和风险 / 边界。
- `gate:grd-005.projected-chart-legibility` 图表主线、阈值、关键点、单位与状态在投影尺寸下完整可读。
- 微型信息增加可信度但不争夺第一阅读层；正文和图注不靠过小字号容纳。
- 异形卡片、高饱和蓝和珊瑚色都具有明确角色，数量受控。
- 动画暂停、禁用或导出 PDF 后，静态层级仍成立。
