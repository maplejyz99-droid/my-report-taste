## 设计推断

- 高级感来自“白色信息中心 + 固定侧轨 + 结论标题 + 受控双语义色”，不是来自把深蓝铺成大面积商务背景。
- 深蓝承担品牌、当前、主要路径和核心证据；浅蓝承担历史、背景、次级范围。沙金通常承担未来、长期、机会、第二对照或温度感，但具体语义仍须按项目重新定义。
- 左侧侧轨相当于低带宽导航：它让 57 页长材料保持方向感，又不占用顶部大色条。
- 同一套骨架能容纳图表、流程、表格、人物、产品和附录，因此适合中长篇投资者与成长说明，而不是只适合单一图表类型。

## 内容与叙事规则

- 页面顺序优先采用：极简封面 → 目录 → 为什么现在 → 章节幕封 → 结论标题 + 证据 → 战略总图 → 分项验证 → 财务/风险 → 产品证据附录。
- 标题写成可验证结论；图表、表格或流程图直接回答标题，不使用中性主题词充当标题。
- 战略总图先显示短期/长期或当前/未来的分工，再用后续页面逐项验证。
- 财务与风险页保留口径、单位、期间和脚注；不能为了投影美观删掉合规证据。
- 照片只用于使命、管理层、产品场景、门店和产品机理，不作为空白填充。

## 视觉与版式配方

- `canvas`：纯白或极浅冷灰；普通页不使用暖白或沙金全页底。
- `rail`：一条窄深蓝侧轨 + 微型章节名 + 页码；重建时使用项目自己的几何导航，不复制 TENTIAL 字标与转角图形。
- `title`：顶部结论标题占宽约 `70%–88%`；副标题、章节标签和页码显著退后。
- `evidence`：两列或三列证据区；大数字、直接标签和低对比网格优先，圆角卡片只用于真正独立的结论块。
- `photo-divider`：约 `45%–55%` 的照片窗与左侧标题/目录配对；照片偏冷、自然、低饱和，人物或产品承担证据职责。
- `data`：主系列深蓝，历史与辅助系列使用浅蓝/灰；沙金只作为第二语义，不承担普通底色。
- `table`：蓝色表头 + 白色主体 + 发丝线；不使用交替彩色行和重边框。

## 媒介适配

- `16:9 PPT`：来源本身为 `16:9`，可直接学习比例关系；正文仍需按中文投影字号重新排版，不复制其微型脚注字号。
- 独立阅读 PDF：可保留高密财务、风险与附录页，但需确保脚注、单位和来源在普通屏幕上可读。
- 短篇组会：只借用侧轨、结论标题和数据配色；不要复制完整八章节叙事。

## 反模式与边界

- 不把本条概括成“海军蓝 + 米色商务模板”；用户对通用海军蓝、石板钴蓝和暖白底的否定仍然有效。
- 不把沙金变成全页背景、普通卡片底或与深蓝各占一半的装饰双色。
- 不复制来源 Logo、转角字标、照片、数据、品牌商品图或原文。
- 不在投影型 PPT 中原样保留来源的超小脚注和高密风险表；应放大、拆解或移至附录。
- 不在每个对象上叠加阴影和圆角；连续表格、流程和图表应保持结构连续。

## 验收标准

- 普通内容页首先被感知为白色/冷白页面；深蓝通常约占 `6%–12%`，沙金通常低于 `3%`，只有明确的战略/对照页可突破。
- 同一语义在全篇颜色一致；深蓝、浅蓝、沙金和中性灰分别有明确职责。
- `gate:grd-007.three-second-dual-semantics` 每页三秒内能读出结论标题、主证据和当前/未来关系。
- 章节页、普通内容页、财务页和附录页共享同一侧轨与微型导航，但没有机械套用同一构图。
- 去色后仍能通过字号、位置、线型和明度看懂证据。
