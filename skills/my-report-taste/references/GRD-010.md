## 设计推断

- 这套源稿应定义为“角色自适应的高证据密度”，而不是笼统的“文字多”或“中高密度”。密度来自结论、主要证据、解释、Bottom line 和来源共同占据页面，并且各自具有职责。
- 页面不是依赖大留白制造高级感，而是依赖稳定页眉／页脚、清晰分区和一项主证据维持秩序；其白色空间主要用于分隔证据，不是为了把内容缩成三个稀疏卡片。
- 原生文字、正式图与公式之间存在替代关系：文字少时必须由足够大的正式证据解释；正式证据少时，文本必须形成论证层级，不能只留下标题和三句口号。
- 源稿的学术感同时依赖“局部可细读”和“全页有主路径”。只复制小字号会变成拥挤，只放大字号并删除口径／来源会变成商业演示。

## 内容与叙事规则

1. 页面地图必须增加 `density_mode`：`text_evidence`、`formula_evidence`、`figure_evidence`、`mixed_evidence` 或 `transition_reset`；密度由页面职责决定，不设全篇统一字数。
2. 每张普通内容页有一个主要阅读任务和足以解释它的证据；定义或方法页不强造研究判断，解释与来源围绕任务展开，Bottom line 按需，不新增无职责的卡片、照片或 KPI。
3. `text_evidence` 页允许较高原生文字量，但必须出现至少两级论证层级、明确分区或直接比较，不能把长段落平铺成一块。
4. `figure_evidence` 与 `formula_evidence` 页可显著减少原生文字，但正式图／公式必须成为中央读取任务，并保留一句解释和可见来源。判断是否过稀看阅读任务是否完成；来源的文本统计不是新稿的最低字数。
5. `mixed_evidence` 页让标题、解释与主要证据有清晰读序，必要时增加收束；不把中央证据拆成等宽卡片墙。
6. `transition_reset` 页可以降低内容占用，承担章节定位或认知清空；低密度必须由转场职责解释，不能连续扩散到普通证据页。
7. 论文来源、口径、变量定义和边界属于证据密度的一部分，不是可以为放大装饰性图形而首先删除的“杂项”。

## 视觉与版式配方

- 常规画幅：`16:9`，以实际模板为先；NAR-001 与 CLR-010 是可选组合，不由密度卡自动加载。
- 普通白底证据页的来源锚点不是固定字数，而是主内容区通常约有 `67%–84%` 的活跃视觉网格；生成时以“occupied but ordered（被证据占据但仍有秩序）”为目标，不机械追逐像素比例。
- 原生文字页：优先一到两列明确论证区、分组标题、重点短语和底部结论条；不用三到六张同尺寸圆角卡把论文论证改写成产品卖点。
- 公式页：公式或形式化定义可横跨页面中部，周围只保留必要变量解释与推论；空白服务公式解码，不算密度不足。
- 正式图页：正式图／机制图可占主内容区的大部分；若图内已有标签，不在四周重复一遍相同文字。
- 比较与边界页：允许更高关系密度，但行、列、情形、结论之间必须直接对应；优先直接标签和行级结论，不依赖图例破译。
- 页脚：可见论文来源保持完整且可读，通常占用稳定底带；不能因为正文变大而缩成不可识别的作者缩写。
- 来源字号只作为形态事实记录。新生成长时专家研讨会稿可接近该信息密度，但仍应先在目标设备检验；15–30 分钟投影稿通过拆页、裁切、重标和分步揭示适配，不通过继续缩字适配。

## 媒介适配

- 长时专家研讨会／会后阅读型 PPT：可接近来源的角色变密度；文本页允许较多说明，正式图页允许大图，影响结论的边界保留，未来议程仅在有来源且任务需要时展示。
- 15–30 分钟学术 oral：保留必要证据职责，不固定页型序列，把复合证据拆为连续页。每页字号变大后仍保留结论、主要证据、必要口径与来源；辅助细节转到下一页或附录。
- 大教室远距离投影：若正文或图内标签需要依赖 `12–16 pt` 才能容纳，判定为需要拆页，而不是直接继承来源字号。
- PDF／会后阅读：可以补回被演讲版拆出的解释和口径，但不得用更小字号堆回同一页，也不得把图缩成论文截图缩略图。
- 动效：只在逐步揭示公式、机制或证据对应关系时使用；静态导出必须保留完整终态和来源。

## 反模式与边界

- 不把葛冬冬密度简化成“每页三张卡 + 一句 Bottom line”，即使颜色和标题已经正确。
- 不把文本单位或活跃网格比例当成机械 KPI；它们是来源锚点和异常检测信号，不替代页面职责判断。
- 不要求每页都达到同一密度。公式页、正式图页、章节页和总结页本来就有不同占用方式。
- 不把低文字量直接判为稀疏；先检查正式图、公式、表格或机制图是否承担了中央证据。
- 不把高文字量直接判为学术；没有主张、层级、证据和来源闭环的文字墙仍不合格。
- 不继承源稿的小字、字体替换、裁切、位图堆积和多母版历史；这些是实现特征或风险，不是个人偏好。
- 不使用第 88–106 页黄色教学产品宣传体系的产品卡、二维码销售页、合作 Logo 墙或营销式稀疏模块来调节节奏。

## 验收标准

- `gate:grd-010.role-adaptive-density` 页面地图为每页声明 `density_mode`，并能解释为什么该页采用文字、公式、正式图、混合证据或转场密度。
- 普通证据页有明确主路径且解释充分；检查无职责留白与稀疏卡片是否削弱信息，不按连续页数判失败，同组对照可以保持相同布局。
- 文字少时检查图／表／公式是否完成主要解释任务；简短定义能自足时可以保留。不得为达到字数或面积阈值添加无关内容。
- 高文字页至少有一个可口述的结论、两级信息层级和清晰分区；读者无需逐字通读才能找到主张与证据。
- 公式、图表标签、变量、单位、论文来源与边界在 100% 成品尺寸可读；无法通过时拆页，不以缩字、截图缩小或口头补充通过。
- `gate:grd-010.dual-scale-qa` 全篇同时通过原尺寸检查和缩略图检查：前者验证局部可读，后者验证高密页、图页和转场页形成有意节奏。
- 与 `CLR-010` 联用时，上方标题、证据色和来源色保持其语义；密度调整不得把酒红标题改黑，也不得用大色块替代证据。
