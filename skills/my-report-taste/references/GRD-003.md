## 设计推断

- 高级感的主要来源不是暗色，而是严格网格、极端尺度差、负空间、稀缺强调色、细线系统和页面密度节奏。
- 内容页背景属于“材质层”而不是装饰插画：观众应感觉它并非平涂，但不应主动注意到某条纹理或光束。
- 本预设可采用高密系统图，前提是空间拓扑先被看懂，且高饱和焦点只有一个。
- 该模式更适合 8–20 页短篇叙事，不适合直接承载 60–100 页连续查表型报告。

## 内容与叙事规则

- 用强幕封把观众视觉状态归零，再进入中高密信息页。
- 章节内按“定义 → 证据 → 机制 → 制度 / 行动”推进，不平均分配每页信息量。
- 高密页面之后安排低密列表或幕封，形成呼吸。
- 一页可组合多个组件，但它们必须共同回答一个问题。
- 照片只在人物、环境、产品或案例真实性确有价值时出现。

## 视觉与版式配方

- 画布：16:9；使用明确列网格和稳定外边距。结构网格不等于必须把整页方格画出来。
- 封面 / 幕封：近黑或深石油蓝全幅背景，巨型编号 / 标题偏置摆放，允许局部越界和非完整圆环。
- 内容页：顶部标题与底部页码固定；主体围绕 1 个主拓扑或 2 个强分区展开；以低对比石油蓝光场承托内容，默认关闭显眼的全页方格。
- 比较组件：独立卡片与连续表格分开处理。独立卡片可使用低对比细边；连续表格使用一块共享蓝灰表面、内嵌发丝分隔线和稳定列网格，选中项优先用字重、明度与直接状态标签增强，必要时只加局部短导轨，禁止再套整行闭合框。风险项用窄色条与文字提示，不为每个方法分配独立底色。
- 层级：以字号、空间、明度和字重为主，颜色为辅。
- 复杂页：中心机制最强，结果端次之，外围环境最弱；避免把所有节点做成同等卡片。
- 低密页：允许纯文字双栏，但标题、行距、栏间距和页脚仍与全篇一致。

## 媒介适配

- PPT：适合公司介绍、招聘、战略、组织文化和愿景章节；章节页可作为明显停顿。
- PDF：短篇可全文采用；长篇仅将其用于封面、幕封和少量系统页，正文回到浅底提高持续阅读性。
- Markdown：先重组页面职责；不得简单套深色 CSS 后原样分页。
- 中英文：用可授权的 CJK 无衬线与现代 Latin grotesk / condensed sans 重建字体角色，不复制品牌专有字体。

## 反模式与边界

- 不将该模式概括成“黑底 + 白字 + 黄点”。
- 不复制 LENZ Logo、原始弧线、背景纹理、高管照片或专有字体。
- 不在每页重复巨型圆环；它只属于封面和章节语法。
- 不为每个节点增加不同高饱和色；单点色必须对应页面中心结论。
- 不把 `canvas` token 当作整页唯一纯色，也不使用明显全页方格去补偿平涂背景。
- 不用交替行色、方法专属底色或整块风险红制造区分；这会把克制的高管叙事变成通用仪表盘。
- 连续表格已有统一表面时，不再为每行建立独立卡片边界，也不为选中行增加四边闭合描边；这会形成第二套围合系统并把整表切碎。
- 不连续安排大量深色高密页，也不靠缩小字号维持信息量。

## 验收标准

- 缩略图总览中能看到强幕封、内容页与安静收束页的密度节奏。
- `gate:grd-003.grayscale-hierarchy` 即使转为灰度，网格、尺度、空间和明度仍能建立主次。
- 内容页原尺寸查看时能感到边缘暗角与局部蓝绿照明，但缩略图中背景不会先于标题、图表或表格被注意。
- `gate:grd-003.shared-surface-family` 比较页所有同级行 / 卡共享同一表面家族；连续表格最多保留一层整体围合，主选项和风险项在去色后仍可通过字重、标签、明度和局部位置标记识别。
- 最复杂页首先读懂空间拓扑，随后才阅读节点文字。
- 每页最多一个高饱和焦点；暖色出现处都能说明它对应的唯一结论。
- 人像、照片、图标和纹理均有明确职责且许可边界可追溯。
