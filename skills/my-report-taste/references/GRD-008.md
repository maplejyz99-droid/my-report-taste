## 设计推断

- 这套 Deck 的统一性不来自“所有页长一样”，而来自固定 Chrome、统一黑白基底、稳定字体尺度和重复斜向几何。
- 黑色章节幕封承担叙事断点；普通内容页立即回到纯白，因此视觉节奏是“暗幕封 → 白内容 → 暗幕封”，不是连续暗色模式。
- 主题色可以不存在。素材颜色、品牌色和局部语义色属于证据层；页面系统本身保持无彩。
- 价值观页面的脚本/衬线显示字体是内容本身的一部分，不是普通正文的字体规则。中文迁移应以高质量无衬线为主体，只在“字体就是证据”的页面使用展示字体。
- 高级感主要由大字号、极端留白、图像裁切、明度对比和少量几何建立，适合设计、产品、创意组织和招聘叙事。

## 内容与叙事规则

- 来源公司的暗色幕封、白色内容与照片节奏可作呈现参考；公司介绍与招聘顺序不是通用内容路线，不因选无彩而加入团队照或招聘章节。
- 章节入口直接标明主题或问题，随后展示任务相关的事实、案例和数据；不强制造价值主张或人物证据。
- 一页只设一个主要构图：大主张、三列案例、单图表、单流程、单照片或单表格，不让多种形式抢焦点。
- 客户 Logo、案例截图和照片只有在证明采用范围、用户类型、工作环境或组织文化时出现。
- 数据页优先大数字 + 单图表；不为了“丰富”增加彩色图例。

## 视觉与版式配方

- `cover/section`：炭黑 `#222222` 全幅，白色标题，深灰 `#555555` 的单一斜向几何；重建时应使用项目自己的几何标记，不复制 Studio 斜杠。
- `content`：纯白 `#FFFFFF` 或中性 `#F7F7F7`，近黑 `#222222` 正文，灰色辅助文字和发丝线。
- `chrome`：左上微型标记 + 英文/中文标签；右上页码；左下项目标识。Chrome 细小但高对比，不抢正文。
- `type`：结论/大数字可占页面宽度的 `30%–60%`；正文保持正常投影字号。中英文主体采用无衬线，展示字体只在有叙事理由时启用。
- `photo`：全幅环境照、半幅人物/作品照、三列案例图或证据拼贴；照片颜色不转化为全局主题色。
- `graph`：黑色主系列、浅灰背景系列、直接标签；局部语义色最多一个。
- `geometry`：斜线、斜切灰带、圆/同心圆和大空白作为空间结构，不用圆角卡片海。

## 媒介适配

- `16:9 PPT`：来源比例与用户常规媒介一致；适合口头讲述、公司介绍、招聘和产品路演。
- PDF：内容页留白充足，适合会后阅读；案例 URL、二维码和细节需要保持清晰。
- 中文化：推荐思源黑体类中文无衬线 + Source Sans/Inter 类英文无衬线；不应机械寻找与来源 Type 3 字体“完全同款”的未知字体。

## 反模式与边界

- 不把本条做成全篇深灰/黑色；暗色只用于封面、目录和章节幕封，普通内容页回到纯白。
- 不从案例截图、客户 Logo、照片或玫红阈值表中抽取颜色建立彩虹主题。
- 不复制 Studio 的斜杠 Logo、精确斜向图形、办公室照片、团队照片和产品截图。
- 不在普通中文正文中滥用脚本体、装饰衬线或超粗字重。
- 不用低对比灰字和超小字号冒充高级感；留白必须来自取舍，而不是删掉必要证据。
- 不把每页做成不同模板；变化必须被固定 Chrome、无彩基底和字体尺度约束。

## 验收标准

- `gate:grd-008.dark-divider-white-content` 缩略图中能看到稳定的“暗幕封 → 白内容”节奏；普通内容页不被任何主题色统治。
- 普通无图内容页的无彩面积接近 `95%–100%`；局部语义色通常低于页面 `1%`。
- 页面构图可以变化，但 Chrome、标题尺度、页码和对齐基线稳定。
- 照片、Logo 和截图都有证据职责，移除后会损失具体信息，而不是只损失装饰。
- 去色后几乎不影响理解；色彩仅增强局部语义或保留素材真实性。
