## 设计推断

- 该模式的高密度不是“文字塞满”，而是多个局部层级围绕同一主题共存：先读页面主张，再扫总图或大图，最后进入正文和注释。
- 它的基本单元不是孤立的指标卡，而是“主张 + 场景 / 人物 + 机制证据 + 对利益相关者的意义”的迷你编辑文章。
- 高级感来自多列网格、照片策划、柔性连接、稳定边界与局部层级，不来自空白量或单个装饰组件。
- 与 `GRD-001` 相比，它更强调人物、场景和社会意义；与 `GRD-002` 相比，它不追求一页一个结论；与 `GRD-003` 相比，它更温暖、生活化且适合长篇阅读。

## 内容与叙事规则

- 一页可容纳多个组件，但必须共同回答一个中心问题；不允许把无关段落因空间充足而并置。
- 使用“页面主张 → 总体关系 → 局部机制 / 证据 → 人物或利益相关者影响”的局部阅读路径。
- 需要总图时，让总图与局部解释在同页保持可见，避免破坏整体—局部关系。
- 人物专题采用“背景 / 制度 → 场景 → 当事人声音 → 组织影响”，照片和文字共同完成证据链。
- 管理层寄语、案例和专题允许保留较长正文，但必须有引导标题、首要引语、清晰分栏和可扫描小标题。
- 跨页节奏在总图、机制、数据、人物、专题和附录之间变化，不连续复制同一种卡片阵列。

## 视觉与版式配方

- 画布：优先 A 系列横向或接近 \(\sqrt{2}:1\) 的报告比例；使用稳定外边距和多列编辑网格。
- 背景：近白为主，淡粉或低饱和暖色用于区分专题区域；避免整页高饱和底色妨碍长时间阅读。
- 主色：红 / 珊瑚为主，橙黄用于渐变过渡；蓝绿只承担明确的语义类别，不平均分配给普通模块。
- 组件：允许圆角照片框、柔和色带、胶囊标签、圆形系统与浅阴影白色模块，但不要求所有内容都装进统一卡片。
- 图片：以真实人物和工作环境为主；裁切应参与页面骨架，不能只是正文旁的小型配图。
- 文字：标题、引导句、小标题、正文、注释和页脚至少形成五级层级；正文虽小，仍需可打印、可放大阅读。
- 密度：高密页面必须保留一条明显的第一阅读路径，并让每个局部区域都有自己的标题、边界与对齐基线。

## 媒介适配

- PDF / 印刷：首选媒介；保持单页高密度和完整上下文，逐页检查打印字号、图注、跨栏阅读顺序和缩放后的清晰度。
- PPT / 现场投影：不作为默认主系统。只有观众拥有同步电子稿、使用高分辨率大屏，或该页被明确安排为停留精读 / 总图讨论时才采用；不得因为“内容很多”自动套用。
- 会后材料：可将现场使用的低密度 PPT 与 `GRD-004` 高密度 PDF 分别编排，二者共享事实但不机械互相导出。
- Markdown：先建立专题、总图、证据和人物案例的内容层级，再生成编辑页；不得按 Markdown 段落长度自动分栏。
- 中英文：中文与英文分别校准字宽、行数和分栏；英文版不能直接沿用中文栏宽和字号。

## 反模式与边界

- 不因原始 Markdown 很长、页面数量想减少或用户没有时间讲完，就自动启用高密度版式。
- 不机械执行“一块卡片一页”的拆分；这会破坏该模式的整体—局部关系并退化成普通卡片 PPT。
- 不以缩小字号、压缩行距、减少页边距代替真正的信息编排。
- 不让每个模块拥有同等视觉权重；页面必须有主张、主图 / 主照片和次级细节。
- 不复制岛村品牌、门店形象、员工照片、官方插画、Logo、原文或业务数据。
- 不把暖色渐变扩展为彩虹配色；蓝绿等辅助色仅用于确有意义的类别。
- 不在短时组会、快速决策会、远距离投影或手机快速浏览中使用整套模式。

## 验收标准

- 缩略图中能先识别页面主题、主图 / 主照片和主要色带，而不是只看到密集小字。
- `gate:grd-004.print-scale-legibility` 在 100% 缩放或目标打印尺寸下，正文、图注和脚注均可连续阅读，无需猜测字形。
- 每页只有一个中心问题，所有模块能说明它们与该问题的关系。
- 总图与局部证据之间具有明确对应；人物照片、插画和色带都有叙事职责。
- 全篇至少包含总图、机制、数据、人物 / 案例和总结等不同页面节奏，不连续复制相同模块阵列。
- `gate:grd-004.activation-threshold` 启用前已逐项通过“启用门槛”，并在交付说明中注明为何该场景适合高密度独立阅读。
