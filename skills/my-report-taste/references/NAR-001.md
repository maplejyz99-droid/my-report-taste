## 设计推断

- “学术味”主要来自研究问题的累积推进、证据完整性、结论强度控制和文献可追溯性，而不是单靠白底、衬线字体或公式装饰。
- 反复出现的研究路线图让多篇工作被解释成一条持续演进的研究计划，增强了专家研讨会的整体性。
- 每页采用“主张 → 证据 → 意义 → 来源”的论文式闭环，使高信息密度仍有明确阅读路径。
- 这套源稿更接近长时专家研讨会与会后独立阅读材料；其准确特征是 `GRD-010` 所定义的“角色自适应高证据密度”：文本页靠分区论证，公式页靠形式化关系，正式图页靠大幅证据，转场页主动降密度。显式字号以 12、14、16 pt 为主，但不应直接推断为远距离投影的安全字号。
- 多母版、多主题和大量位图表明源稿可能由多份研究材料汇编而成。未来应重建其原则，不应把整份 125 MB 文件当作干净模板直接复制。

## 内容与叙事规则

1. 先用一句话定义中央研究命题，再建立覆盖主要成果的研究路线图；路线图必须表达依赖、层级或研究问题演进，不得退化为论文目录。
2. 章节按研究能力或问题层级推进，而不是按论文发表时间、作者或素材顺序机械排列。
3. 每页只承担一个主要职责：背景、问题、方法、结果、比较、机制、边界、综合或未来工作。
4. 标题优先写成可验证的研究判断，例如“专用小模型超过通用大模型”，避免只写“实验结果”“方法介绍”等主题标签。
5. 标题下允许一条解释句，明确证据意味着什么；主要视觉区域交给公式、实验表、机制图、程序／工作区证据或直接比较。
6. 结果页必须同时回答“结果是什么、与谁比较、依据是什么、为何重要”；必要时用 Bottom line 收束，但不得改变原始结论强度。
7. 方法页必须解释机制与因果链，不把框图当作装饰；公式保留变量关系，表格保留口径、样本、阈值和来源。
8. 每个主要章节至少包含一次综合或回到路线图的定位页，使听众知道当前工作如何推进中央命题。
9. 结尾必须包含适用边界、限制、开放问题或未来研究议程，不以泛化的“Thank you”代替学术闭环。
10. 外部非平凡主张、论文图表和引用必须在页脚或演讲者备注中可追溯。
11. 单篇论文 oral 的路线图也必须是研究路线：中央问题 → 两类失败机制 → 对应方法 → 证据链 → 边界／开放问题。仅把模块名称串成“问题 → 方法 → KPI”的流程图，不算研究路线图。
12. 页面地图必须在开始制作前标注证据形态与版式族。方法、结果、机制、边界等不同职责应采用不同主要轮廓，不得先固定万能骨架再替换内容。

## 视觉与版式配方

- 画幅：常规 16:9；来源画幅可以复用，但必须按实际演讲时长和阅读距离重新分页。
- 页面基底：普通内容页使用纯白或极浅冷灰；封面可使用 `#7D1E2F` 酒红学术场，但不得把大面积强色扩展到所有内容页。
- 联动模式：调用本模式时同时调用 `GRD-010 + CLR-010`。`GRD-010` 约束角色变密度、证据占用和页型节奏；`CLR-010` 约束标题、证据与来源色。
- 主色角色：生成适配默认以 `#7D1E2F` 承担页面上方主标题，以 `#A12746` 承担结论前缀、关键数字与 Bottom line，以 `#FAE9EC` 承担洗白证据底；`#0077CC` 只承担论文来源或链接。深蓝、紫色只在确有研究层级／方法语义时作为受控辅助色。
- 字体角色：前半部分主标题的来源事实是粗体无衬线，公式、论文式证据、部分结果页与后段编辑页使用衬线／数学字体。生成时默认以安全无衬线字体承载酒红主标题，以衬线字体承载公式、论文式正文或关键研究判断；不得把整套标题统一改成黑色衬线大标题。
- 页面骨架：左上或上方为结论标题，右上为微型研究层级标签；中央为一项主要证据；底部依次放结论条、论文来源与页码。
- 证据形式：按认知任务选择公式、表格、直接比较、机制图或过程图；不得为追求“学术感”而无职责地添加公式、论文截图或复杂框图。
- 强调方式：通过字重、酒红短语、浅色证据底、关键行／列和 Bottom line 建立层级；避免多主色、卡片墙、胶囊标签墙和营销式大数字拼贴。
- 图像原则：用户已有正式图且在目标尺寸可读时优先保留；不可读论文截图应裁切、重标或按数据重绘，不允许缩成证据缩略图。
- 跨页节奏：研究路线图／章节定位 → 方法机制 → 结果证据 → 综合判断；相邻页应变换证据轮廓，但保持导航、标题、来源和颜色角色稳定。
- 密度角色：页面地图必须声明 `density_mode` 为 `text_evidence`、`formula_evidence`、`figure_evidence`、`mixed_evidence` 或 `transition_reset`。普通证据页应呈现“被证据占据但仍有秩序”，不能连续退化成标题、三张稀疏卡片和大片无职责留白。
- 短篇学术 oral 仍应覆盖至少五类职责化轮廓：研究路线、公式或形式化定义、机制／论文正式图、定量结果证据、边界与未来议程。若源材料确实缺少某类证据，须在页面地图中记录原因并采用最接近的学术职责替代。
- 论文来源优先在可见页脚中给出作者、论文题目以及已知的会议／期刊和年份，再附本页 Figure／Table／Section 定位；只写“He et al., Table 3”可留在备注中，但不足以单独承担可见论文页脚。
- 卡片和流程节点仅用于确有离散阶段、角色或状态的关系，不作为默认容器。连续两页使用同一“标题 + 等宽卡片／箭头 + Bottom line”骨架时必须重做其中至少一页；全篇缩略图应能区分路线图、公式、机制图、结果表、定性证据和边界页。

## 媒介适配

- 专家研讨会、长时学术组会：可保留接近来源的角色自适应高证据密度，但仍须在目标屏幕和教室后排检查公式、表格标签与脚注。
- 15–30 分钟组会或大会演讲：保持同一研究叙事与视觉语言，拆分复合证据、放大关键图表，每页只保留一个主要读取任务；不得通过继承 12–16 pt 小字号压缩页数。
- 15–30 分钟单篇论文演讲不得以“时间短”为由把研究路线缩成方法框图、把论文证据统一重画成 KPI 卡片，或删除限制与未来工作。可以拆页、裁切和重标，但证据职责必须保留。
- 论文答辩：强化研究问题、贡献、方法、实验、局限和未来工作的闭环，并让路线图与答辩章节一致。
- 会后阅读型 PPT/PDF：保留必要解释、口径、来源和边界；演讲型省略信息应补入正文或附录。
- PPTX 派生 PDF：必须复核字体嵌入、Unicode 文本提取、公式比例、标题裁切、图表标签和逐页渲染结果。

## 反模式与边界

- 明确排除第 88–106 页的黄色教学产品宣传系统，包括大面积黄色／金色背景、产品模块、合作 Logo、部署方案、联系方式、二维码和营销式话术。
- 该负反馈限定于“纯学术汇报中混入教学产品宣传体系”，不得扩大为用户普遍不喜欢黄色或所有产品汇报。
- 不复制来源论文内容、实验数据、作者信息、品牌、Logo、二维码、产品素材、原始插画或页面成品。
- 不把“白底 + Times New Roman + 小字号 + 公式”误当成学术风格；没有研究主张、证据和来源闭环的页面不属于本模式。
- 不把“白底／酒红 + 衬线大标题 + Bottom line + 简写来源”误当成已经复用本模式；若中央区域长期由统一圆角卡片、流程箭头和大数字占据，仍属于 UI 外壳化失败。
- 不把 `CLR-010` 中的葛冬冬酒红猜成 `#8B1E3F` 莓红或 `#58162F` 暗紫，也不把所有主标题统一设为 `#171820`／黑色，再用酒红 Bottom line 或表头补偿。
- 不把来源后半部分个别黑色／深中性标题扩大成默认规则。明确选择完整作者视觉预设时保留酒红上标题；仅借用叙事结构时不强制该颜色；若确需源稿多章节色路由，必须在页面地图中声明标题色为何转紫或转蓝。
- 不把单篇论文的 method overview 命名为 research map 后直接通过路线图验收；路线图必须展示研究问题、机制、证据与开放边界之间的关系。
- 不继承源稿的 33 字体、多母版、多主题、位图堆积和 125 MB 体积；生成稿应建立一个主视觉系统并控制资产分辨率。
- 不把完整论文表格或截图缩小到不可读；不能通过口头解释弥补页面上不可解码的主要证据。
- 不因追求原稿密度而牺牲投影可读性，也不因降低密度而删除必要口径、边界与文献溯源。
- 不把原稿密度简化成统一小字号，也不把适配理解成统一降密度。原生文字少的普通证据页必须由足够大的公式、正式图、表格或机制图解释；若两者都没有，则属于稀疏商业化改写。
- 不把字体替换、缺字、标题裁切、对象溢出或随机版式变化记录为个人品味。

## 验收标准

- `gate:nar-001.structural-fidelity` 整套材料能用一句话说明中央研究命题，并能从路线图追踪每个章节如何推进该命题。
- 每页有一个主要职责和一个可口述的结论；主题型标题已改为研究判断或明确问题。
- 方法、结果、比较、边界与未来工作均有对应证据，且证据与标题结论一致。
- 主要非平凡主张、外部图表和论文成果具有可追溯来源；Bottom line 不夸大证据强度。
- `gate:nar-001.paper-source-closure` 每张主要证据页具有可见的论文级来源，至少包含作者／题目和本页 Figure／Table／Section 定位；来源未知的字段明确留空或标为未知，不补造会议与年份。
- 15–30 分钟单篇论文稿至少出现研究路线、形式化方法、机制或正式图、定量结果、边界／未来议程五类页面职责；全篇不连续复制同一种卡片或图表壳子。
- `gate:nar-001.research-agenda-ending` 收尾在 Questions 之前明确区分“证据支持什么、仍受哪些限制、下一步研究什么”，不以三条 Takeaways 直接替代研究闭环。
- 普通内容页首先被感知为白色／冷白学术画布，酒红及辅助色具有稳定语义，不出现黄色产品宣传系统。
- 每张主内容页上方标题默认首先被感知为 `#7D1E2F` 酒红；允许结论前缀用 `#A12746`、后半句用 `#666A73`，但不得整条标题统一为黑色。标题默认使用粗体无衬线，公式与论文证据再使用衬线／数学字体。
- 公式、表格、图表、页脚和来源在目标尺寸可读；高密度页面同时通过 100% 原尺寸检查与全篇缩略图检查。
- 每页已声明 `density_mode`；除计划内章节／转场外，不连续出现两页以上“标题 + 三个稀疏卡片 + 大片无职责留白”。文本少的证据页有可读的大幅正式证据，文字多的证据页有明确结论、两级层级和清晰分区。
- 字体已嵌入或使用经过验证的安全回退；PPTX 与 PDF 均无缺字、裁切、溢出和不可提取文本。
- 未复制未知许可的论文内容、品牌资产或原页面成品；原始 PPTX 未被修改或长期复制。
