## 设计推断

- “学到布局但没有学到配色”通常不是色值略有偏差，而是颜色角色、面积比例和跨页节奏错误。
- 颜色参考必须转换为语义 token，再按面积配额应用；只从参考中挑几种醒目的颜色会制造彩虹化。
- 深色路线尤其依赖明度阶。若层级可以靠白、灰和蓝灰完成，就不应新增饱和暖色。
- 暗色背景的审美验收必须检查空间分布，而不只检查十六进制色板；单色平涂、强方格和强纹理都可能偏离同一个参考。
- 浅色体系必须同时验证色相气质、背景温度和页面角色面积；不能把“一个主色 + 白卡”当作自动合格。

## 内容与叙事规则

- 每条路线先指定一个主参考与一个主色族；不同路线分别实现，不在同一文件中平均混合。
- 颜色只编码“当前 / 次要 / 风险 / 未知”等语义，不固定绑定方法名称。
- 风险或异常同时使用文字标签、位置、线型或右删失符号，避免只靠另一个高饱和色传达。
- 比较组件的同级项先统一表面；连续表格的主选项使用更高字重 / 明度、直接标签或局部短导轨，风险项使用窄边 / 状态文字，禁止交替换底和整行闭合选中框。只有真正独立的卡片才可使用低对比细描边。

## 视觉与版式配方

- Goodpatch：近白底 + `#0B6FCA` 主蓝 + 同色浅阶；珊瑚 `#FE7265` 仅为低频异常。
- LENZ：近黑边缘 `#01080C`、石油蓝基底 `#071F29`、柔和青蓝照明 `#10323E`–`#173F4B`、统一蓝灰表面 `#1B313A` / `#243B45`、白灰文字；生成默认不使用饱和黄 / 金，焦点可用暖灰白 `#C5CBC9`，风险只用低面积陶土色。
- Plus Alpha：浅灰白底 + 深红 `#AE0000` + 玫红 `#D64F72` + 淡粉 `#FDF1F1`；结构越界可用靛灰 `#4E4E64`。
- 岛村：暖白 `#FDF9FA` + 莓红 `#B9273B` + 玫红 `#D45B6C` + 淡粉 `#F7E1E6`，通过明度阶管理高密度。

## 媒介适配

- PPTX：在实际投影比例下检查主色面积、暗部层级和例外色频率；不能只看色板。
- PDF：渲染全部页面并查看缩略图总览，确认跨页不存在随机换色或连续高饱和疲劳。
- 深色派生 PDF 必须额外核验蓝灰层级没有在转换后压成一片黑。

## 反模式与边界

- 不把“专业”默认翻译为海军蓝、亮蓝、红色、黄色四套状态色并列。
- 不因参考中出现一次暖色，就把暖色扩展到标题、卡片、图表系列和流程节点。
- 不用单一 `#07222E` 或类似深色铺满内容页，再用明显全页网格制造“设计感”。
- 不用交替行色、方法专属色、整行风险红或黑色断层区分比较对象。
- 不把“选中”翻译为连续表格中的白色四边闭合框，也不让每个普通行都形成独立围合；一张表只能有一层主要围合系统。
- 不把强云纹、颗粒墙纸或霓虹渐变当作“非纯色背景”；光场必须安静到不成为观察对象。
- 不用几何 QA、字体嵌入或文件可打开来替代颜色审美验收。
- 不把石板钴蓝、石墨靛蓝、灰蓝、通用海军蓝列为默认备选，也不通过降低饱和度掩盖旧式企业色气质。
- 不把暖白、米白和纸张色作为高密度 PDF 的默认背景。
- 不在普通内容页复用封面／章节页的大面积主题色；饱和主色必须先通过页面角色与面积门禁。
- 不把本条负面反馈扩大为用户不喜欢深色、红色或蓝色；否定对象是错误混配和错误面积比例。

## 验收标准

- 每个内容页通常不超过两个显著饱和色相；第二色相必须有明确语义。
- Goodpatch 内容页的珊瑚风险色通常低于页面面积的 2%。
- LENZ 生成路线默认无饱和黄 / 金；若未来确有唯一机制焦点需要暖色，面积必须低于 1%，且不能填充普通卡片或图表系列。
- LENZ 背景应通过九宫格取样显示多个近黑 / 石油蓝明度；缩略图中光场不能比主标题或证据组件更显眼。
- 同一比较表的所有常规行必须共享一个表面 token；选中与风险状态在灰度模式下仍可由标签、字重、明度和局部位置标记识别，不依赖整行闭合描边。
- 去色查看时，标题、主系列、次要系列、边界和风险仍可区分。
- 全部页面必须完成原尺寸视觉检查和缩略图总览；颜色脚本只作为门禁，不能替代人工判断。
